# Fetch Employees

Application React qui affiche le profil d'un employé (photo, prénom, nom et email) récupéré depuis l'API.

# Fonctionnalités

1. Un profil est affiché dès le chargement, grâce à un employé d'exemple stocké dans le state (useState).
2. Un bouton Get employee envoie une requête fetch à l'API et remplace le profil affiché.
3. Le profil est affiché par le composant EmployeeCard.

# Technologies utilisées

-React
-TypeScript
-Vite
-API
